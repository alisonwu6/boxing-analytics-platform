# Collaboration Rules

## General
- Keep the repository structure clean
- Do not upload large raw datasets directly to GitHub
- Use clear commit messages
- Do not modify other people's work without discussion

## Folder Usage
- Put Streamlit prototype code in `streamlit_demo/`
- Put algorithm-related code in `ml/`
- Put exploratory notebooks in `notebooks/`
- Put reports and generated outputs in `outputs/`

## Branching
- Use feature branches for major work
- Merge to main only when the work is stable
