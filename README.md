# Boxing Analytics Platform

## Folder Structure
- backend/ APIs using FastAPI
- data/ stores raw, processed, and sample datasets
- docs/ stores architecture notes and project logs
- frontend/ Web UI using React
- ml/ stores preprocessing, algorithms, and model-related code
- notebooks/ stores exploratory work
- outputs/ stores figures and reports
- scripts/ stores reusable command-line utilities (e.g., data checks, conversion, export)
- streamlit_demo/ stores the Phase 1 dashboard prototype
